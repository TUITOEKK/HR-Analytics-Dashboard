## 📌 Project Overview

This project is an **HR Analytics Dashboard built using Microsoft Excel** to transform employee data into meaningful insights that can support Human Resource decision-making.

HR departments deal with large amounts of employee information. When this information is stored only in spreadsheets and tables, it can be difficult to quickly identify workforce patterns, trends, and areas that require attention.

This dashboard provides HR with a **visual and interactive way to explore employee data**, monitor workforce indicators, and support data-driven decisions.

### 🎯 Main Objective

The objective of this project is to demonstrate how raw HR data can be transformed into:

**Raw Data → Analysis → Visualization → Insights → HR Decisions**

---

# 🏢 Why HR Needs This Dashboard

Employee data contains valuable information about an organization's workforce.

However, simply having employee records does not automatically provide useful insights.

An HR dashboard allows HR teams to quickly understand:

- 👥 Workforce size and composition
- 🏢 Employee distribution across departments
- 💼 Job roles and positions
- 👨‍💼 Employee demographics
- 💰 Salary and compensation patterns
- 📈 Employee performance
- 📅 Attendance and absence patterns
- 🚪 Employee attrition and turnover
- 📊 Workforce trends and patterns

Instead of manually going through hundreds or thousands of employee records, HR can use the dashboard to **quickly identify important patterns and areas that may require further investigation.**
